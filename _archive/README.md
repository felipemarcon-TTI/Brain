# _archive

Servidores MCP standalone antigos (minimais), guardados só por histórico.
**Não são deployados** — a funcionalidade já está embutida no `viennapet/`
(Bling + WooCommerce + WordPress).

- `bling-mcp/` — MCP Bling mínimo, OAuth local via callback HTTP (`webbrowser` +
  `HTTPServer` na porta 8080), tokens em `~/.bling/tokens.json`. Substituído pelo
  Bling do ViennaPet (OAuth web + persistência no Railway).
- `woocommerce-mcp/` — MCP WooCommerce/WordPress mínimo (`mcp.run()` stdio).
  Substituído pelo Woo/WP do ViennaPet.

Eram cópias locais sem git na máquina; movidas pra cá só para não perder o histórico.
